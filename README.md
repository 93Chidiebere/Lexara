# eXARA: Gamified Language Data Collection

**eXARA** is a full-stack, gamified platform designed to accelerate and incentivize the collection of high-quality language data (especially for low-resource languages).

## Overview
Training robust Natural Language Processing (NLP) models requires massive amounts of text and speech data. eXARA crowdsources this data by turning translation, transcription, and validation tasks into engaging, gamified experiences.

## Tech Stack
- **Frontend/Backend:** TypeScript, React, Vite
- **Styling:** Tailwind CSS

- eXARA is live https://exara.online
